# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email [pata10102004@gmail.com](mailto:pata10102004@gmail.com) with a concise reproduction, affected route or dependency, impact and suggested mitigation.

The maintainer will acknowledge reports within seven days and provide a remediation status once the issue is triaged.

## Scope

This repository is a public Next.js portfolio deployed through Vercel Git Integration. Security-sensitive reports include dependency vulnerabilities, deployment configuration, content injection, exposed credentials and redaction failures in published OpenScreen recordings.
